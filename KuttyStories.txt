String methods


| Function                | Simple meaning                                          |
| ----------------------- | ------------------------------------------------------- |
| `length()`              | Number of characters in the string.                     |
| `charAt(index)`         | Gets one character at a position.                       |
| `substring(start)`      | Gets part of a string from a position.                  |
| `substring(start, end)` | Gets part of a string between two positions.            |
| `equals()`              | Checks if two strings have exactly the same text.       |
| `equalsIgnoreCase()`    | Same as `equals()` but ignores uppercase/lowercase.     |
| `contains()`            | Checks if a word or character exists inside the string. |
| `startsWith()`          | Checks whether the string begins with something.        |
| `endsWith()`            | Checks whether the string ends with something.          |
| `replace()`             | Replaces characters or words.                           |
| `trim()`                | Removes spaces from the beginning and end.              |
| `toUpperCase()`         | Converts everything to uppercase.                       |
| `toLowerCase()`         | Converts everything to lowercase.                       |
| `split()`               | Breaks one string into many strings.                    |
| `concat()`              | Joins two strings together.                             |
| `isEmpty()`             | Checks if the string has zero characters.               |
| `indexOf()`             | Finds the first position of something.                  |
| `lastIndexOf()`         | Finds the last position of something.                   |


| Function                | Meaning                                                |
| ----------------------- | ------------------------------------------------------ |
| `isBlank()`             | Checks if string is empty or only spaces. *(Java 11+)* |
| `strip()`               | Removes Unicode spaces.                                |
| `stripLeading()`        | Removes spaces only from the start.                    |
| `stripTrailing()`       | Removes spaces only from the end.                      |
| `repeat(n)`             | Repeats the string n times.                            |
| `compareTo()`           | Compares two strings alphabetically.                   |
| `compareToIgnoreCase()` | Same but ignores case.                                 |
| `matches(regex)`        | Checks if the string matches a regex pattern.          |

| Function          | Meaning                                   |
| ----------------- | ----------------------------------------- |
| `intern()`        | Uses the String pool.                     |
| `contentEquals()` | Compares with StringBuilder/StringBuffer. |
| `join()`          | Joins many strings together.              |
| `format()`        | Creates formatted text.                   |
| `valueOf()`       | Converts another datatype into a String.  |

| `Arrays.sort(arr)`       | Sorts the array.                                   |
| `Arrays.equals(a,b)`     | Checks whether two arrays are identical.           |
| `Arrays.fill(arr,value)` | Fills every element with the same value.           |
| `Arrays.copyOf(arr,n)`   | Makes a copy of an array.                          |
